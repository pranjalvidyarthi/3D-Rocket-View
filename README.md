# 🚀 3D Rocket View

An interactive **3D Rocket Visualization** built using **HTML, CSS, and Three.js**. This project showcases a rocket model in a 3D environment with realistic rendering, smooth animations, and an immersive visual experience directly in the browser.

## ✨ Features

- 🚀 **3D Rocket Model** – Visualize a rocket in a three-dimensional environment.
- 🌌 **3D Environment** – Immersive space-inspired background.
- 🎥 **Interactive View** – Explore the 3D scene from different angles.
- ✨ **Smooth Animations** – Enjoy fluid 3D rendering and animations.
- 💻 **Browser-Based** – Runs directly in a modern web browser.
- 📱 **Responsive Design** – Designed to work across different screen sizes.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and layout |
| JavaScript | Interactivity and functionality |
| Three.js | 3D graphics and rendering |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/pranjalvidyarthi/3D-Rocket-View.git
```

### 2. Navigate to the Project Directory

```bash
cd 3D-Rocket-View
```

### 3. Run the Project

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.
